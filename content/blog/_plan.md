Files starting with `_` are not published. Each post is `content/blog/<slug>.md`.
Status: ✅ published · ✍️ next up · ⬜ planned. ★ = pillar page (long, links out to its cluster).
"Trend" posts cover what's moving in 2026 and need a fact re-check every quarter.

## Writing rules

- Answer the search query in the first 100 words. Then go deep.
- Every fact about IIT Madras comes from study.iitm.ac.in (link it). Every number gets a source or is labelled as an example/assumption.
- No invented statistics, testimonials or "studies show". If we don't know, say so.
- Write like a senior student explaining to a junior: direct, specific, Indian context (₹, lakh/crore, IST, Indian companies).
- One idea per paragraph. Tables for comparisons, numbered lists for steps, callouts for traps.
- At least 3 internal links (Skills notes, Qualifier Pack, PYQs, related posts) and 2 authoritative external links.
- At least 2 original SVG diagrams in `public/blog/<slug>/` using the `.blog-figure` classes.
- End with an FAQ section (`## Frequently asked questions`, each question as `###`).
